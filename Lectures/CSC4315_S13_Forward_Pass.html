Hold on to Lab 5's rule: in X @ W1, column j of W1 collects everything flowing into hidden neuron j. Getting rows and columns crossed is the single most common error today, and it produces numbers that look perfectly plausible.

Hidden scores. Neuron 1: 2.0·1.0 + (−1.0)·(−1.0) + 0.5 = 3.5. Neuron 2: 2.0·0.5 + (−1.0)·2.0 − 0.5 = −1.5. Neuron 3: 2.0·(−2.0) + (−1.0)·0.0 + 1.0 = −3.0. You did exactly this in Lab 5.
2
Hidden activations. σ(3.5) = 0.971, σ(−1.5) = 0.182, σ(−3.0) = 0.047. One neuron strongly on, two mostly off.
3
Output score. 1.0·0.971 + (−2.0)·0.182 + 0.5·0.047 + 0.2 = 0.971 − 0.365 + 0.024 + 0.2 = 0.830.
4
Prediction. σ(0.830) = 0.696. The network gives a 70% probability that this example is a yes.
🧮
The sign in the exponent

σ(−1.5) must come out below 0.5. If yours is 0.818, you computed 1/(1 + e−1.5) — the sign of the score was lost. Check the easy fact first: negative score, probability under a half.

Part 3 · 15 minutes

The same pass in three lines

And then a whole batch, without changing a character.

Lab 9, task 2python
def forward(X, W1, b1, W2, b2):
    Z1 = X @ W1 + b1          # (n, 3)
    A1 = sigmoid(Z1)          # (n, 3)
    Z2 = A1 @ W2 + b2         # (n, 1)
    A2 = sigmoid(Z2)          # (n, 1)
    return Z1, A1, Z2, A2

Assert, do not eyeball

Part 4 · 10 minutes

What every number is

Leave able to point at any one of the thirteen and say what it does.

Point and explain

Each answer is one sentence.

W1[0, 2] = −2.0. It multiplies input 1 on its way into hidden neuron 3; because input 1 is 2.0 here, it contributes −4.0 to that neuron's score and is the main reason neuron 3 is off.

W2[1, 0] = −2.0. It is how hidden neuron 2 votes on the output. A negative weight means: the more neuron 2 fires, the less likely a yes.

b2 = 0.2. The output's starting lean before any hidden neuron votes: with all three hidden neurons silent, the network would say σ(0.2) = 0.55.

If W2[0, 0] doubled to 2.0, would A2 go up or down? Up: neuron 1 is at 0.971, so its vote grows by about 0.97, the output score rises to about 1.80, and σ(1.80) ≈ 0.86.
