Part 2 · 20 minutes · live

Retrieval-augmented generation

"It does not know my documents."

A model cannot know your course policies, your clinic's protocols or last week's memo. Retraining it for every document is impractical. Retrieval-augmented generation fetches the relevant passages at question time and puts them in the prompt, with instructions to use only them and cite them.

1
Index the documents so they can be searched — the demonstration uses TF-IDF so every score is inspectable; production systems use embeddings from session 24.
2
Retrieve the top passages for the question.
3
Ground the prompt: use only the supplied context, cite a source label for every claim, say so if the context is insufficient.
4
Generate, then check that each claim points at a source.

What is the capital of Ghana?                    → transformer_scope.txt 0.0
Retrieval always returns something

The third query has nothing to do with the course, and the retriever still returned a document — with a score of zero. An honest system acts on that score: it says the documents do not cover the question, rather than letting a model write a confident answer around an irrelevant passage.

Part 3 · 15 minutes · live

Tools, memory and an honest loop

The demonstration agent — CSC4315_S28_Demo_A_Small_Honest_Agent — deliberately contains no language model. Its planner is three if statements, so every decision is a line you can read. It has a calculator that evaluates arithmetic and nothing else, a session lookup over the course map, retrieval, and a memory you can print.

three steps of the looptext
What happens in session 25?     → lookup_session: Session 25 — Attention, computed by hand
calculate 17 * 240 / 100        → calculator: 40.8
Send an email to my professor   → None: I have no tool that can do that, so I will not pretend to.

In a real agent a language model replaces the keyword planner, choosing tools and arguments from a description of each. That makes it far more flexible — and moves every failure on the diagram into a component you cannot read line by line. Domain-specific agents work best when the tools, documents and permissions are narrow and the checks are explicit.

Where this course ends

You arrived, many of you, unable to write a function. You have since built a neural network from matrix multiplications, derived and checked its gradients, trained it on real images, rebuilt it in three frameworks, broken and repaired it, evaluated it honestly, borrowed networks that see and write, computed attention by hand, and made a frontier model measurably better at a task. None of it is magic to you any more — and that is the most useful thing an AI course can leave behind.
